### 🪟 Windows only

- **[[Windows Autopilot]]** / device preparation policies
- **Windows Hello for Business**
- **Windows LAPS**
- **BitLocker** (disk encryption via Intune)
- **Endpoint Privilege Management (EPM)**
- **[[Windows Autopatch]] / Hotpatch**
- **Enrollment Status Page (ESP)**

### 🍎 Apple only(iOS/iPadOS + macOS)

- **Apple Business Manager / Volume Purchase Program (VPP)**
- **FileVault** (disk encryption équivalent BitLocker mais pour macOS)

### 🤖 Android only

- **Android Enterprise enrollment profiles** (fully managed, dedicated, work profile)
- **Google Zero Touch**
- **Samsung Knox Mobile Enrollment**

### 🔒 iOS/iPadOS + Android only

- **[[App Configuration Policies]]**
- **[[App Protection Policies]] (MAM/APP)** > no MAM for Windows

### 🌍 Cross-platform

- **[[Compliance Policies]]** = Windows, iOS, Android, macOS, Linux
- **[[Conditional Access]]** = follows compliance policies
- **Microsoft Cloud PKI** = Windows, iOS, Android, macOS
- **Settings Catalog** = Windows, macOS, iOS/iPadOS, Android (settings change based on the OS)
- **[[Remote Help]]** = Windows, macOS, Android; pas iOS
