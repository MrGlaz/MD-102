
>**Servicing channels:**

- **Current Channel** = feature updates ASAP, multiple/year, frequent testing
- **LTSC** = feature updates every 2-3 yrs, security/quality only, for stability-critical devices (medical, industrial)
- **Semi-Annual Channel** = deprecated, replaced by deferral policies

>**Update types:**
- **Quality updates** = monthly, security/bug fixes, small & low-risk
- **Feature updates** = 2x/year, new capabilities, large, needs planning/testing
- **Preview updates** = optional, pre-release testing (drivers, rollups), catch issues early

>Good process is to create three feature update rings:

- **Pilot ring** (5% of devices, 0-day deferral): Receives updates immediately for testing
- **Standard ring** (70% of devices, 30-day deferral): Receives updates after pilot validation
- **Conservative ring** (25% of devices, 90-day deferral): Receives updates after extended testing
